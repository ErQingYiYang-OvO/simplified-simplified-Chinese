# 再简字字典

以现行简体字为基础进一步简化字形，采用思源黑体的笔画与排版风格。简中版是字体底板；简中版与日文版共同提供部件。第一阶段只开展 Regular 字重设计。

## 打开字典

双击 `start_dictionary.cmd`，浏览器会打开本机字典。需要 Python 3.10 或更新版本，无需安装其他库。关闭启动窗口即可停止服务。

字典只提供查询、造字法筛选、轮廓展示和刷新目录，没有新增、修改、删除功能。三个页面分别是：

- **字典**：展示原字、造字法、造字思路，以及关联的新字形轮廓。
- **部件**：按名称、来源查询并展示部件轮廓。
- **字形**：按原字查询并展示字形轮廓。

界面只在本机 `127.0.0.1` 提供服务，不需要网络连接。预览直接显示 SVG，不依赖系统安装新字体。框架搭建时三个目录均为空。

## 项目结构

| 位置 | 内容 |
| --- | --- |
| `sources/` | 原版简中、日文思源黑体，许可证与完整性校验记录。 |
| `design/` | 造字法、设计规则、手稿；已有五种造字法名称已保存。 |
| `components/index.json` | 部件目录：编号、名称、来源、轮廓路径。 |
| `components/svg/` | 可复用部件的 SVG 轮廓。 |
| `components/query.py` | 按名称或来源查询部件。 |
| `glyphs/index.json` | 字形目录：编号、原字、轮廓路径、可选部件编号列表。 |
| `glyphs/ai/` | Illustrator 可编辑工作文件。 |
| `glyphs/svg/` | 经确认的字形 SVG 轮廓。 |
| `glyphs/recipes/` | 后续自动拼装配方。 |
| `glyphs/query.py` | 按原字查询字形。 |
| `fontforge/` | 后续 FontForge 编辑工程。 |
| `data/dictionary.json` | 字典：编号、原字、造字法、造字思路、字形编号。 |
| `data/query.py` | 查询字典及筛选造字法。 |
| `library.py` | 只读目录访问、路径校验及关联检查。 |
| `gui.py`、`viewer/` | 只读字典 GUI。 |
| `font_tools/` | 后续原字体轮廓提取、字体构建及审计工具的位置。 |
| `proofs/` | 新旧字对照、词语与正文样张。 |
| `build/` | 可重新生成的临时产物。 |
| `releases/` | 确认发布的字体及对应记录。 |
| `tests/` | 目录关联、查询与只读服务测试。 |

## 命令行查询

在项目目录中执行；脚本从任意工作目录启动也能找到本项目。

```text
python -B components/query.py
python -B components/query.py ム
python -B glyphs/query.py 能
python -B data/query.py 能
python -B data/query.py --method 意字
python -B library.py
python -B gui.py --open
python -B -m unittest discover -s tests -v
```

`library.py` 检查编号是否重复、SVG 是否存在、字形是否引用有效部件，以及字典的原字与字形是否一致。查询不修改项目文件。

## 入库约定

### 字形调整与确认

用户于 2026-09-27 明确：今后制作与调整阶段只交付 Illustrator 导出的 SVG 草稿，放在 `glyphs/ai/drafts/`。用户确认满意后，才将该轮廓写入字体、正式字形目录、部件目录和字典。未经确认的草稿不覆盖已入库的 SVG、AI、SFD 或测试字体。

“能”的第四版经用户手动微调并明确确认后已入库。最终轮廓以 `glyphs/versions/glyph-0001/v4-approved/user-confirmed.svg` 为准，不再强制套用第三版的尺寸和间距参数。

详见 `data/README.md`。未来由制作流程编辑目录文件，GUI 只负责读目录。每次入库后执行目录检查，再在 GUI 点击“刷新目录”。所有路径相对项目根目录填写。

同一原字可以保留多个方案，每个方案使用独立编号。部件与字形均以 SVG 为交付给预览界面的轮廓；AI 和 SFD 是编辑工程。字形必须确定一份当前有效的 SVG，避免不同工具中出现两个“最新版”。
